            Returns on mutual funds (XIRR)

            The yearly rate at which the money you put in, the money you took out and the statement value balance. It counts only the history on your CAMS or KFintech statement, and only funds whose transactions cover the whole holding and add up to the units held. A fund that cannot be worked out is listed with the reason, never estimated. It is money-weighted, so it is not comparable with a fund's published return, and it is not tax advice.

            Fund Return a year Since Put in Taken out Value Gain

            Tax lots on mutual funds

            Each purchase is a lot, and each sale uses the oldest lots first. Only funds whose transactions cover the whole holding and add up to the units held are shown with figures; any other fund is listed with the reason, never estimated. Proceeds are the amounts printed on your statement. Only the days held are given, because whether a gain is short or long term depends on the kind of fund and the purchase date. Check it against your own working: this is not tax advice.

            Which files, which password, what about duplicates?

            Files this app reads

            • NSDL or CDSL consolidated account statement (PDF): stocks, ETFs, bonds, sovereign gold bonds and the mutual fund folios section. This is the one to start with.
            • CAMS or KFintech statement (PDF, detailed): mutual funds with their transactions. Optional, and it adds transaction history.
            • Not read: spreadsheets, screenshots, contract notes and broker profit and loss reports.

            The password

            • NSDL and CDSL statements use your PAN in capitals. CAMS and KFintech use the password you chose when you asked for the statement.
            • It is tried as you type it, then in capitals. It is sent only to this app on your machine, used to open the file, and never stored or logged.

            Duplicates and overlaps

            • The same file twice changes nothing. A file read by an older version of this app is replaced with a fuller read.
            • Statements are never added together. Stocks come from the newest demat statement, and mutual funds from one statement (the newest, CAMS or KFintech first on the same date), so overlapping periods are not counted twice.

            Warnings

            • After each read the app compares the total printed on the statement with the rows it read. A gap means some rows were not recognised, and values may be too low. You can still save it; the gap stays listed on the Overview until a statement reads fully.

              How to restore a backup

              Restoring replaces the database, so it is done from the command line with the app stopped. The backup is checked first, and the current database is kept aside, not deleted.

              PYTHONPATH=src .venv/bin/python -m portfolio.backup restore data/backups/<file> --force

              An encrypted backup (.gpg) also needs the private key, which should be kept somewhere other than this machine.

              Your data and privacy

              • Stored: …
              • Identifiers: only the last four characters of folio and demat account numbers. No PAN, name, address, phone number or email.
              • Never stored: the statement PDF or its password. They are read in memory and dropped.
              • Where: on this machine. Nothing is sent to anyone.
              • What leaves this machine: only when you press Refresh prices, requests for public price files (AMFI, NSE, BSE). They contain nothing about your holdings.
              Export all data

              Export saves everything above as one JSON file. Deleting removes statements, holdings, transactions and prices (the activity log stays) and takes a backup first.

              Display

              Theme

              Kept in this browser only: the theme, the last page you opened, how the holdings list is sorted and filtered, your saved views and the two dates you compared. No holdings, amounts or search text.

              Delete all data?

              This removes every imported statement, holding, transaction and price from this machine. A verified backup is made first, and if that fails nothing is deleted.

              Export first if you want a readable copy. Type delete all data to confirm.
